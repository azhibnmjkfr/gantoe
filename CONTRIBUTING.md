# Cara Kontribusi ke GANTOE

Terima kasih sudah mau bantu! GANTOE sengaja dibuat sederhana agar mudah dikontribusi.

## Aturan Emas

1. **Jangan ubah folder `vendor/`.** Itu library pihak ketiga.
2. **Satu PR = satu perubahan.** Jangan campur fitur + refactor + ganti gaya dalam satu PR.
3. **Jaga privasi.** Jangan pernah menambahkan kode yang mengunggah file user ke server, analytics, atau pelacak.
4. **Tetap vanilla.** Jangan tambahkan framework / build tool tanpa diskusi dulu di Issue.
